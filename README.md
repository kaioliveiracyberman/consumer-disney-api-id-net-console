# ConsumerDisneyIdApi

Aplicação console em C#/.NET para consumir a Disney API.

## Endpoint utilizado

https://api.disneyapi.dev/character/423

## Retorno

A aplicação exibe no console:

- Nome do personagem
- Imagem do personagem

## Como executar

```bash
dotnet run
```
